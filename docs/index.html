Open-source personal knowledge base with Notion-like pages and Anki-like spaced repetition. Self-hosted, offline-ready, open source.

View on GitHub Quick Start

Everything you need

✍

Rich Text Editor

Notion-like editor with slash commands, tables, task lists, code blocks, and image uploads. Powered by Tiptap.

🃏

Spaced Repetition

SM-2 flashcard algorithm with Again/Hard/Good/Easy scheduling. Create cards from selected text instantly.

📊

Statistics

GitHub-style review heatmap, streak tracking, per-deck mastery breakdown, and accuracy metrics.

🔒

Self-Hosted

Single SQLite file you own. Deploy with Docker in one command. No cloud, no subscriptions, no tracking.

🌓

Dark Mode & PWA

Beautiful light and dark themes with adjustable UI scaling. Install as an app on any device.

✍

Daily Tasks

Recurring tasks on your home screen with a 7-day activity chart. Stay on track every day.
